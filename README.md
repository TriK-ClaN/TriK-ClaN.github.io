# Neot Interview Guide

Interactive preparation guide for the Neot Capital Investment Analyst internship interview.

## Contents

- **Briefing:** interview countdown, readiness score, priority tiers and a 48-hour plan
- **Neot Profile and Role Decoder:** company facts, platforms, recent transactions and the offer translated into evidence to bring
- **Study:** nine modules spanning project finance, debt sizing, modelling, accounting, valuation, returns, investing, EV economics and asset management
- **Practice:** flashcards, quiz, statement drills, Fleet Case Lab, Returns Lab and a timed mock interview
- **Prepare:** Story Builder, French lexicon and an interview-day checklist

## Structure

```
index.html              Entry point
assets/css/styles.css   Design system with light and dark themes
assets/js/core.js       Icons, storage, utilities and progress tracking
assets/js/data/         Study, practice and reference content
assets/js/tools.js      Financial engine and interactive labs
assets/js/views.js      Page views
assets/js/app.js        Navigation, routing, theme and search
```

The site is fully static and needs no build step. Progress and notes are stored locally in the browser.
